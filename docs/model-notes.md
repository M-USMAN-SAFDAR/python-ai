The specific 3B instruction model card lists a full context capacity of 32,768 tokens:
https://huggingface.co/Qwen/Qwen2.5-3B-Instruct

Actual context allocated by Ollama may be lower. The 128K family overview must not be assumed to apply to this specific 3B model.

The 0.50 PKR per 1,000 tokens in the exercises is fictional practice pricing. Local Ollama does not bill per API token; hardware and electricity still have costs.

The cleaner follows the lesson's `.capitalize()` requirement. It can change acronyms, names, and code, so preserve original casing in a production application where it matters.
